## What to build

Create a menu using a do-while loop.

- Create a do-while loop for your menu.
- You will have 3 conditions.
  - If the user types 1, the program will print "Hello {user}".
  - If the user types 2, the program will count down from a number.
  - If the user types 3, the program will exit.
  - Print at the end: "The Menu is closed".
- You will not be provided any variables. All you will be provided is an empty main function, and you will build your code from scratch.
- You will determine what variables you need. I will leave it up to your interpretation on how you approach this assignment.
